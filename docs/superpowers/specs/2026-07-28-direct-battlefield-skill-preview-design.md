# Project Expedition 直接戰場與技能結果預演設計

日期：2026-07-28

狀態：互動方向已核准；待書面規格確認

本規格細化
`2026-07-28-single-screen-animation-first-app-shell-design.md`，修正目前正式版的
重複人物框、狀態標籤、技能資訊不足與傷害不可預測問題。

## 玩家成果

玩家不需要先理解「特化、觸發、Component」等系統術語。第一次點技能後，
戰場直接預演這名角色對目前目標會造成的傷害、命中、狀態、連鎖與接力結果；
點敵人便施放，再點同一技能則快速攻擊目前目標。

爽感與清楚度來自「先看見即將發生什麼，再看見每一段確實發生」，而不是
增加戰報或規則文字。

## 根因與單一視覺責任

- Pixi 已繪製人物、姓名、HP、狀態與選取輪廓，React 又顯示相同內容，造成
  人物與按鈕框重疊。
- `BattlefieldUnitControls` 只應提供透明、至少 48px 的語意觸控區；正常渲染
  不得顯示卡框、姓名、HP 或狀態。
- Pixi 是人物外觀、姓名、HP、狀態、目標、目前角色與命中回饋的唯一視覺來源。
- Pixi 失敗時，React fallback 才顯示簡化姓名、HP 與可操作輪廓。
- 通用按鈕 CSS 不得覆蓋技能局部控制；移除散落在技能格外的 `i` 按鈕。

## 戰場資訊層級

- 所有存活單位常駐姓名與 `目前 HP / 最大 HP`，HP 條同步呈現比例。
- 目前角色額外顯示 `攻擊` 與現有 `強化`；目前目標額外顯示有效 `防禦` 與
  `削弱`。
- 點擊非待命狀態的人物可開啟不改變布局的短暫詳情層，查看完整攻、防、
  狀態與裝備核心。
- 目標使用人物腳下鎖定環、瞄準線與元素色；目前角色向前站位並亮起武器；
  下一位角色使用接力光點；已行動角色退後降亮。
- 燃燒、毒素、蓄潮與削弱附著在人形、護甲或原 HP 區，不另開浮動標籤框。
- 任務標題縮為不遮人物的單行列；六段接力能量位於保留的戰場安全區。

## 技能待命與施放

1. 第一次點技能：設定待命技能、原地展開簡短說明並預演目前目標，不出招。
2. 點任一存活敵人：使用待命技能攻擊該敵人。
3. 再點相同技能：使用待命技能攻擊目前鎖定目標。
4. 點另一技能：切換待命技能與預演。
5. 技能施放後清除待命狀態、自動切換下一位角色；目前目標存活時繼續鎖定。
6. 播放期間鎖定輸入；完成後立刻恢復操作。

沒有待命技能時，點敵人只改變目前目標；沒有目前目標時，再點技能不施放，
而由存活敵人的人物輪廓提示玩家指定目標。

## 技能預設資訊

六個技能格維持 2×3，預設顯示真正的技能名稱與可比較數值，不再只顯示
「多段、疊層、爆破」：

`烈焰連斬　威力 +8　3擊　燃燒 +2`

依技能內容顯示最多三個主要值：威力、命中／彈射次數、層數、削防、強化或
每層消耗值。完整隨機範圍、來源與融合材料留在技能管理頁。

## 精確結果預演

預演必須由 `simulation-core` 使用與正式出招相同的純函式規則產生。React
不得重寫或估算戰鬥公式；預演不可改變正式戰鬥狀態、順序或事件序號。

單次命中的可讀算式為：

`角色攻擊 + 技能威力 + 強化 - 有效防禦 = 每擊傷害`

多段以重複事件呈現，不把傷害改成不可追蹤的乘法加成。觸發追加、狀態消耗、
核心效果與接力餘震保持獨立事件，預演摘要依實際事件加總。

選中技能後，操作區突出：

- 每擊傷害、命中次數、觸發追加與預計總傷害。
- 目前目標 `HP 136 → 0`、擊殺、OVERKILL 與剩餘狀態。
- 多目標技能逐一顯示各目標傷害，再顯示總傷害。
- 狀態顯示 `燃燒 2 → 4`、`防禦 12 → 8`、`強化 0 → 6` 等前後值。
- 未成立的追加效果以淡化的預演殘影表示，並用一個當前事實說明原因，例如
  「目標未燃燒」；不顯示長篇規則。

目標 HP 條以半透明區段預覽扣血；命中點、狀態增減、彈射路徑、消耗吸入、
處刑與溢傷標記直接出現在相關人物身上。

## 技能與接力因果

不要求玩家學習一套輸入／輸出符號或事先閱讀技能關聯圖。只在當前條件真正
影響結果時顯示具體原因：

- 目標燃燒先發光，再連向會追加爆破的技能。
- 上一位角色的元素軌跡連向目前角色，相關技能才發光。
- 削弱護甲、達標層數或強化光環先動，再播放由它觸發的追加段。
- 下一位角色接棒後，只高亮因上一招而變強的技能；展開時顯示如
  「布蘭上一棒使用火屬，本次多彈 1 次」。

融合技能依模擬順序預演完整動作，不暴露 Component 術語。例如：
`連斬 3 次 → 燃燒 +2 → 最後一擊引爆`。不會發生的段落變暗。

## 實際出招與爽感

- 輸入、蓄力、移動、每次命中、目標反應、狀態變化與接力依序播放。
- 每一擊立即跳出自己的傷害，最後才聚合為 `TOTAL`；追加、暴擊、擊殺與
  OVERKILL 使用不同尺寸、節奏與鏡頭層級。
- 角色與目標之間保留無 UI 遮擋的攻擊走廊；說明層在施放時收起。
- 接力每棒增加軌跡、命中層次、粒子與鏡頭；第六棒集中回收全隊殘留軌跡並
  完成終結，不靠戰報傳達高潮。

## 技術與狀態邊界

- 待命技能是 Web 顯示狀態，不進入 `GuildBattleState`，也不決定戰鬥結果。
- `simulation-core` 新增可測試的預演契約，與正式解析共用單一事件來源。
- 預演摘要只投影傷害、治療、狀態、削弱、強化、擊殺、溢傷與目標路徑。
- 切換角色、完成施放、勝利、撤離或戰鬥重建時必須清除待命技能。
- 鍵盤、觸控與螢幕閱讀器均能選技能、指定目標、快速施放與關閉詳情。
- Reduced Motion 保留預計 HP、數字、輪廓與狀態前後值，移除長位移與閃爍。

## 驗收

- 正常 Pixi 渲染下沒有可見的 React 人物卡框、重複姓名、重複 HP 或重複狀態。
- 第一次點技能不造成戰鬥事件；點敵人或再點同一技能才施放。
- 每個技能格具有可比較數值；選中後可看見對目前目標的精確總傷害。
- 預演與正式施放的逐目標傷害、HP、狀態、擊殺及 OVERKILL 完全一致。
- 玩家不閱讀戰報即可看出傷害來源、觸發原因、技能內順序與角色接力原因。
- 375×667、390×844、430×932 與 1280px 均無捲動、人物／說明重疊或操作遮擋。
- Pixi fallback、Reduced Motion、鍵盤與觸控均可完成完整六人接力戰鬥。
