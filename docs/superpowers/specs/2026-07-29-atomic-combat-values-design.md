# Project Expedition 原子數值與組合放大設計

日期：2026-07-29
狀態：方向已確認，待書面規格審閱

本規格在衝突處取代：

- `2026-07-27-deterministic-six-hero-loot-build-design.md` 的基礎效果、融合元件與數值區間。
- `2026-07-28-battlefield-as-skill-explanation-design.md` 的「本批不重新平衡」限制。

## 產品目標

所有單一來源從最小整數開始；品質或強度每升一級只增加 1。單人、無前置狀態的
技能只造成小傷害。大數字只能由玩家建立的疊層、條件、跨角色接力、追擊、彈射、
擴散、消耗與終結事件逐筆相加。

不使用玩家傷害倍率、暴擊倍率、脆弱倍率或隱藏戰力。角色成長來自刷取更好的
效果組合與固定值，不來自角色升級。

## 統一品質與強度

所有可刷取物共用五級：普通 1、優良 2、稀有 3、史詩 4、傳奇 5。

- 每件物品與每個技能元件都有 `qualityRank`，範圍固定為 1–5。
- 主要效果等於 `qualityRank`；品質每升一級，主要效果固定 +1。
- 次要強度可在 1–`qualityRank` 內獨立隨機，保留同品質不同用途的刷取差異。
- 顯示品質顏色只代表 `qualityRank`，不代表元素。
- 技能星級不等於品質：星級 1–3 代表融合元件數；品質代表每個元件的強度。

## 角色、敵人與裝備尺度

- 六名角色的基礎攻擊、防禦、速度、治療皆從 1 開始；角色差異由被動與組合職責
  表現，不用高面板區隔。
- 攻擊武器主值等於品質：普通 +1、優良 +2、稀有 +3、史詩 +4、傳奇 +5。
- 防具、治療與速度主值採同一 1–5 尺度。
- HP 使用獨立的低量級事件預算，不作為品質強度：英雄基準 10；普通敵人約
  8–18、精英 20–40、首領 50 以上，再依任務事件量配置。
- 敵人防禦與攻擊使用 1–5 威脅階級；不得保留目前 18–188 的舊攻防尺度。
- 裝備詞綴不再提供無條件的大量平面攻擊；數值詞綴為 1–5，優先改成有條件的
  追加事件、路由、疊層、削弱或強化。
- 普通裝備 0 詞綴；優良／稀有 1 詞綴；史詩／傳奇 2 詞綴；傳奇可有第二核心。

## 原子傷害模型

所有結果由 `simulation-core` 產生具因果 ID 的獨立事件。

- 第一擊：`max(1, 角色基礎攻擊 1 + 武器主值 + 技能威力 - 有效防禦)`。
- 後續多段、彈射與爆炸不重複加入角色與武器主值；每段只使用該元件的 1–5
  強度，避免把完整第一擊複製六次。
- 每個元件每次施放只能使用一次追擊強度預算；多段把預算拆成小事件，不得在
  每一擊重新複製完整觸發強度。
- 追擊、反應、核心與被動每次各建立一筆 1–5 的事件。
- 削弱在造成它的事件之後生效，不回頭增強同一擊。
- 強化只加入下一個符合條件的事件或技能；使用後立即清除，不能跨回合永久累積。
- OVERKILL 只記錄已存在事件的溢出，不另外放大傷害。
- 總傷害是所有可追溯事件的加總；React、Pixi 與預覽不得重算。

## 技能品質、特化與融合

每個一星技能元件包含：

- 主要威力：固定等於品質 1–5。
- 疊層、觸發追加與特化強度：各自在 1–品質內獨立隨機。
- 屬性、特化與觸發條件仍由公開任務掉落池決定，不抽牌、不用機率觸發。

六特化只改變事件用途與數量：

- 爆炸：第一目標承受第一擊；其他目標承受 1–5 強度事件。單體折返需要條件或核心。
- 疊層：增加 1–5 層，不複製完整第一擊。
- 削弱：攻擊後降低 1–5 防禦，服務後續事件。
- 連鎖：最低 2 路、最高 6 路；後續路由各造成 1–5。
- 強化：讓下一位角色取得 1–5 的一次性強化。
- 多段：第一擊後追加 1–5 次小命中；追加命中各造成 1–5。

二星／三星融合保留來源元件與個別品質：

1. 第一元件永遠執行第一擊及其基礎效果。
2. 第二、第三元件先檢查各自條件；未成立時完全不攻擊、不疊層、不觸發。
3. 已成立元件才建立自己的效果與事件，因此三星不是無條件三倍傷害。
4. 更換、拆解與重組仍完整保留來源技能及品質。

## 條件、屬性與接力

- 每次施放前建立不可變的狀態快照；「目標已有燃燒／毒素／蓄潮」只能讀取施放前
  的狀態，技能不能先附加狀態再自行滿足條件。
- 火、草、水反應只讀取前一事件或前一角色留下的異屬性資源。
- 每消耗一層建立一筆獨立事件；不是把總層數乘進單一公式。
- 核心可增加路由、保留層數或建立新事件，但每個核心強度仍為 1–5。
- 第二至第六棒不再免費獲得固定餘震。只有實際成立的前後屬性、狀態、強化、
  削弱或路由條件才能延續接力。
- 第六棒沒有假倍率；終結只釋放前五棒真實保存的層數、觸發與待結算事件。
- 相同因果 ID 的規則只能觸發一次；有限事件鏈完整播放，超大鏈可聚合演出但保留
  精確逐筆結果。

## 掉落、品質與既有存檔

- 每場仍只掉落 1 個技能；裝備數量沿用任務與敵人掉落規則。
- 基礎掉落以普通為主；Overkill、全滅、首領寶箱等條件只提高品質階級機率，
  不直接增加技能或武器基礎傷害。
- 裝備主要效果由品質直接決定；技能品質決定主要威力及次要強度上限。
- Profile 升級至 v5。舊裝備依既有稀有度映射為 1–5；舊技能各欄位依原範圍的
  相對位置映射為 1–5，保留星級、元件、來源與配置。
- 遷移不得讓舊高數值直接進入新公式；失敗時保留原存檔並回到安全狀態。

## 玩家呈現

- 技能格先顯示 `總傷｜命中數｜主要變化`，不把總傷與 `×N` 並排成疑似乘法。
- 第一次點擊預演時，在戰場上逐段顯示第一擊、已成立元件、追擊與反應路徑。
- 詳情分成「基礎」與「組合追加」：玩家能看出單人技能很小，以及哪些前置讓它
  逐步放大。
- 品質、星級、屬性、特化與觸發使用不同固定視覺語法，不共用顏色含義。

## 驗收

- 所有品質、技能強度、詞綴強度與核心強度均限制在 1–5。
- 所有角色基礎攻擊為 1；所有攻擊武器主值精確等於品質階級。
- 普通一星技能在無裝備、無前置狀態下只產生小傷害；不得自然破百。
- 普通一星、無裝備、無前置狀態、單一敵人的總傷上限為 4。
- 任意品質的一星技能搭配同品質裝備，但沒有施放前狀態或隊友因果時，總傷上限為 30。
- 未成立的融合元件產生 0 傷害、0 疊層及 0 追加事件。
- 技能不能自行滿足「目標已有狀態」；削弱不增強產生削弱的同一擊；強化用後歸零。
- 後續多段不重複角色與武器主值；破百結果的因果祖先必須至少包含三名不同角色。
- 預演與正式事件逐筆一致，總傷等於 damage／reaction 事件加總。
- v1–v4 存檔遷移後沒有任何舊尺度攻擊、技能、詞綴或核心值。
- 受影響測試先 RED 後 GREEN；批次完成後執行一次 `pnpm check` 與一次受控
  `pnpm test:e2e`，並確認測試伺服器連接埠已關閉。
