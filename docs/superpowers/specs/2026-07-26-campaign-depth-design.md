# 戰役縱深與區域推進設計

## 玩家可見成果

- 公會遠征由 3 場擴成 4 區、12 場狩獵。
- 戰役包含 18 種可辨識敵人、6 名 Boss、4 套軍令 Build。
- 每場都有明確處刑順序、壓力機制、Build 對策、敵人專屬掉落、殲滅寶箱與三段高潮。
- 桌機與手機都能看懂區域進度、目前戰線、下一個解鎖目標、全戰役完破與重刷狀態。

## 契約

- `ZoneDefinition` 是跨資料與 UI 的穩定契約，包含區域識別、敘事、調色、轉場文案與依序排列的任務 ID。
- `QuestDefinition.zoneId` 明確宣告歸屬。
- `GuildGameContent.zones` 提供完整區域順序。
- 戰役仍由任務陣列順序線性解鎖，避免 UI 擁有推進規則。

## 內容工廠與驗證

- 共用工廠只處理狩獵裝備、敵人、三段高潮與任務的重複結構。
- 四個區域分檔作者資料，聚合檔只負責順序。
- 驗證器保證：
  - 4 區、12 任務、12 狩獵、18 個唯一敵人、6 個唯一 Boss、4 Build。
  - 每個任務恰好屬於一區，且恰好有一場狩獵。
  - 狩獵引用的敵人都存在於任務。
  - 每個敵人都有壓力特性、視覺身分與專屬掉落。
  - 每場都有殲滅寶箱與 opening / execution / annihilation 三段提示。
  - Build、Boss、護衛與對策引用不懸空。

## 爽感連動

- 第四套「軍令風暴」以每張卡觸發鋼鐵回聲，提供不需要等待條件的連續爆點。
- 每區三場形成「教機制 → 放大壓力 → 區域決戰」節奏。
- 關卡資訊先說要打誰、用什麼破、會掉什麼；避免玩家進戰鬥後才理解。
- 完破不封死內容，轉為全區可重刷並突出紀錄與專屬掉落。

## 非目標

- 不調低傷害、不加入稀缺限制、不為平衡削弱 Build。
- 不在此批新增鍛造、牌組編輯、挑戰或圖鑑；這些屬第四批。
