# Project Expedition 連招清晰度與戰鬥爽感 V2

日期：2026-07-28

狀態：玩家方向已核准

本規格取代 `2026-07-28-battlefield-as-skill-explanation-design.md` 中「戰鬥技能格
不得顯示觸發名稱」及「每個引擎事件各自播放」的限制；其單畫面、戰場操作與
simulation-core 權責邊界繼續有效。

## 1. 玩家成果

玩家在出招前能看懂「條件 → 效果 → 下一棒」，出招後能直接從人物、狀態、
軌跡與節奏看見相同因果，而不是閱讀事件日誌。

核心循環是：

1. 比較六招現在會造成的實際結果。
2. 看出已成立、出招時判定與尚缺的連招條件。
3. 預見這招會替下一棒點亮哪些技能。
4. 施放後看見條件逐一轉化成追擊、連鎖與終結。

## 2. 固定數字語言

- 禁止使用 `30 ×3` 或任何可能被理解為乘法的排列。
- `段` 是本次實際扣除 HP 的獨立傷害事件數。
- `追擊` 是由觸發條件額外建立的傷害事件數。
- `總傷` 是所有本體、追擊、反應與接力傷害的實際加總。
- 個別傷害顯示在受傷單位；總傷只在整招結束時顯示一次。
- OVERKILL 獨立累積，不與普通傷害或段數混合。

## 3. 六技能格

維持 3×2、無捲動。每格固定三層：

1. 屬性圖形與 2–4 字行動名稱。
2. `2段　總傷30　燃+3`。
3. 一星顯示 `開戰✓ → 追傷6`；二、三星顯示 `連招 2/3 已亮`。

條件狀態只有：

- `ready`：金色勾號，現在已成立。
- `pending-impact`：橘色圓點，命中、彈射、擊破等出招時判定。
- `not-ready`：灰色缺口，明示 `缺燃燒`、`缺上一棒火屬` 等缺件。

技能仍可在條件未成立時施放；技能格顯示的總傷必須已排除未觸發部分。

## 4. 第一次點擊：連招軌

第一次點擊只預演，不施放。原說明區改為最多三個並排組件：

`① 開戰 ✓ / 追傷6`、`② 目標燃燒 • / 火鏈3段`、
`③ 上一棒火屬 / 尚缺`。

連招軌下方只保留兩個結論：

- `本次：5段｜2追擊｜總傷126｜燃+6`
- `接棒：萊拉新亮2招`

點擊不同敵人時，六技能結果、條件狀態、連招軌與下一棒預告必須同步更新。
二次點同技能施放；預演中的每個數字與正式結算完全一致。

## 5. 下一棒關係

simulation-core 應以正式純函式結算預演目前技能，再比較下一名角色六招在
施放前後的觸發狀態。Web 只顯示新從 `not-ready` 變成 `ready` 的技能。

戰場用一道能量路徑連到下一名角色；該角色本人與新亮技能數量同步脈衝。
不展開六人頭像，不常駐顯示下一名角色的六張技能卡。

## 6. 玩家節拍，不是事件日誌

正式施放將引擎事件保留為真相，但投影成五個玩家節拍：

1. `windup`：施法者前衝、目標鎖緊。
2. `base`：本體段數快速完成。
3. `trigger`：條件圖形點亮並轉化成追擊。
4. `reaction`：彈射、迴響、擴散、消耗集中爆發。
5. `relay`：能量交給下一棒；第六棒轉為 `finisher`。

同一組件的連續傷害以 55–90ms 間隔播放，最後一段才加重停頓。非傷害事件
不得插入獨立空白動畫，避免播放像逐條閱讀紀錄。

## 7. 六種特化與三屬性

- 爆炸：內縮後放射衝擊。
- 疊層：元素光點逐層吸附，顯示前後層數。
- 削弱：護甲輪廓裂解並掉落碎片。
- 連鎖：逐目標連線；單體時離場後折返。
- 強化：能量飛向下一棒並點亮受益者。
- 多段：快速連擊，末段重擊。

火使用熱浪、殘焰與低頻爆破；草使用孢子、毒霧與腐蝕；水使用壓力波、
回捲軌跡與治療光環。不得只用同一粒子換色。

## 8. 六棒升壓與終結

- 第 1–2 棒建立狀態與第一次追擊。
- 第 3 棒啟用連招計數與更強命中停頓。
- 第 4 棒提高環境能量、飽和與路徑殘影。
- 第 5 棒鏡頭收緊並顯示終結預告。
- 第 6 棒短暫靜默與暗場，逐條件高速點亮後一次釋放。

終結依序顯示：狀態集中、白閃、主爆發、延遲總傷、OVERKILL、敵人碎裂，
接著無文字阻隔地進入戰利品噴發與最多 20 件單頁總覽。

## 9. 技術邊界

- simulation-core 產生正式技能結果、組件條件狀態、段數、追擊與下一棒差異。
- Web 只把語意資料映射成繁體中文短語與版面。
- Pixi 只播放已分組的視覺節拍，不決定傷害、觸發、順序或目標。
- 不新增觸發條件、技能、平衡乘法或戰鬥隨機性。
- 音效與震動失敗不得阻塞戰鬥；Reduced Motion 保留所有數字與因果。

## 10. 驗收

- 375×667、390×844、430×932、1280×800 均為單畫面且無操作區重疊。
- 六技能格不存在 `×N`；段數在前、總傷具名在後。
- 每個一星組件及選中技能的全部組件均顯示條件、狀態與觸發結果。
- 連招軌、戰場預演、正式傷害、狀態、下一棒與 OVERKILL 完全一致。
- 多段、追擊、彈射、單體迴響、削弱、強化與第六棒終結均有不同演出證據。
- 事件播放不出現無數值、無狀態、無路徑、無人物變化的空節拍。
- E2E 完成新手第一戰、六棒遞增、勝利與戰利品流程，且測試連接埠會關閉。

## 11. 非目標

- 不新增角色、敵人、任務、掉落種類或養成系統。
- 不調整戰鬥平衡與掉落機率。
- 不重新設計任務、裝備、技能管理及戰利品資料模型。
