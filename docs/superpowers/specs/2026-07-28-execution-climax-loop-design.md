# Project Expedition 處刑高潮與再戰閉環

日期：2026-07-28

狀態：玩家已核准「六人連動處刑機器」方向

## 1. 玩家成果

敵軍在第六棒前歸零時不再像屍體繼續挨打，而是進入可辨識的破勢處刑窗。
玩家選擇第六名角色的終結型態，看到五次接力餘震集中、全軍終結、OVERKILL
與敵軍碎裂，之後直接收取整頁掉落並可再刷一次。

## 2. 處刑窗

- 戰鬥仍為 active、所有敵軍 HP 為 0、且本回合尚有角色未行動時，進入處刑窗。
- 處刑窗保留倒地敵人、目標與累積狀態；敵人顯示破勢姿態，不使用一般死亡淡出。
- 剩餘角色仍可調整順序，第六名角色從六招中選擇終結的元素與特化外觀。
- 處刑預演顯示「回收 5 次接力餘震、處刑力、OVERKILL」，不顯示對 0 HP
  目標的普通小傷害。
- 正式處刑不再對倒地敵人追加一般傷害或狀態；所有力量轉為接力餘震與終結。

## 3. 情緒優先級

戰鬥主要事件固定為：

`遠征勝利 > 全軍終結 > OVERKILL > 擊破 > 元素反應 > 追擊 > 狀態 > 強化`

- 同一次技能若包含擊破、OVERKILL或終結，被動、強化與治療仍保留引擎事件，
  但合併到高優先節拍，不得單獨覆蓋高潮。
- 玩家與輔助技術不得顯示 `battle_open`、事件 ID、`已播放 N 個事件`或原始引擎訊息。
- 螢幕閱讀器收到與畫面一致的短語、具名數字與事件類型。

## 4. 六棒升壓

- 第1–2棒：建立狀態與第一次追擊。
- 第3棒：接力軌與命中停頓明顯升級。
- 第4棒：環境能量、殘影與衝擊範圍增加。
- 第5棒：敵軍歸零時進入破勢，顯示「第六棒準備處刑」。
- 第6棒：短暫暗場，五次餘震高速聚合，最後一次主爆發顯示處刑力與OVERKILL。

每棒只保留一個主情緒；低優先結果附著在人物、狀態與軌跡上。

## 5. 技能因果

- 一般技能維持「條件 → 行為 → 下一棒」三層資訊。
- 處刑窗的六張技能統一顯示 `處刑力`，並以屬性、特化與技能名稱決定終結型態。
- 選中後戰場目標顯示「破勢 → 處刑」，命令區顯示回收次數與最終結果。
- 二次點同技能立即處刑；不要求重新選擇已倒地目標。

## 6. 戰利品接續

- 終結播放完成後，收取按鈕成為畫面唯一主操作。
- 戰利品維持最多20件單頁、材料合併顯示、點擊展開詳情。
- 稀有與推薦掉落使用更強落地延遲、光暈與震動，但不逐件阻塞玩家。
- 保留「整理裝備、配置技能、再刷一次」三條直接路徑。

## 7. 技術邊界

- simulation-core 定義處刑窗、處刑預演與正式事件，不由 React 或 Pixi 決定結果。
- Web 只投影玩家短語、操作狀態與單畫面版面。
- Pixi 只呈現破勢姿態、聚合與終結，不改變 HP、OVERKILL或順序。
- 不新增技能、觸發條件、角色、敵人、任務、乘法公式或戰鬥隨機性。
- 保留 `AGENTS.md` 與 `docs/AI_DEVELOPMENT_SPEC.md` 的既有未提交變更。

## 8. 驗收

- 早期全滅後仍能辨識敵軍處於破勢，而非一般死亡。
- 第六棒預演不出現 `總傷0`、小傷害或對屍體疊層；顯示處刑力與5次回收。
- 正式處刑事件以 victory 作結，finisher 之前沒有被動事件覆蓋高潮。
- 畫面與無障礙文字均無原始 trigger ID、事件計數與重複句號。
- 375×667、390×844、430×932、1280×800 無頁面捲動、遮擋或點擊區重疊。
