# 戰術沙盤奇觀層設計

## 目標

讓戰場第一眼像軍團在沙盤上交鋒，而不是六張資訊卡互相比數字；所有視覺只服務目標感、連鎖感、衝擊感與爽感。

## 現況

- 單位卡提供完整資訊，但主要視覺仍是三對三卡片列。
- 已有衝擊粒子與 Build 主題，缺少軍團規模、攻擊路徑與陣型崩解。
- 玩家能讀結果，但較難一眼感覺「我的 Build 正沿哪條路線撕開敵陣」。

## 視覺層

### 軍團陣型

- 每個英雄與敵人擁有固定、可重現的微型兵群。
- 英雄由左下向中央推進，敵軍由右上壓迫。
- 單位卡保留為 HUD，兵群位於卡片後方且不可互動。

### 目標與攻擊路徑

- 選取敵人時顯示鎖定環、路徑線與 Build 色彩。
- 預演時路徑呈現蓄力，不偽造尚未發生的傷害。
- 播放時依真實 impact 目標點亮命中、擊破與 Overkill 狀態。

### Build 與敵人差異

- retaliation：厚重直線與盾牆脈衝。
- ricochet：分岔彈射軌跡。
- status storm：擴散式風暴波紋。
- boss 與精英使用更大的核心輪廓，但不改戰鬥數值。

## 架構

- 新增純展示 `BattlefieldTacticalLayer`。
- 輸入只包含目前可見單位、已選目標、Build motif 與既有 impact。
- 所有兵群位置由固定索引產生；禁止 `Math.random`。
- React 與 CSS 不推導傷害、死亡或戰鬥結果。

## 可讀性

- 沙盤層 `aria-hidden`、`pointer-events: none`，不妨礙卡片操作。
- 文字、HP 與教學焦點永遠位於沙盤層上方。
- 行動版降低兵群密度與光效，不隱藏目標路徑。

## 驗收

- 相同輸入永遠產生相同陣型。
- 選取、命中與擊破狀態皆來自現有戰鬥狀態。
- command 與 playback 畫面都有沙盤層。
- 行動版無新增遮蓋或水平溢出。
- 元件測試、流程測試與 `pnpm check` 通過。
