# Phase 04R 可玩核心循環設計

日期：2026-07-23  
狀態：已由使用者核准方案 1

## 目標

把目前的唯讀 Snapshot 改成第一個真正可玩的垂直切片：

```text
固定軍令
→ 決定性戰鬥回合
→ 勝利或撤退
→ 回收素材
→ 返回基地
→ 製造並裝備角甲重盾
→ 進入更強的第二場戰鬥
```

## 本批範圍

- 四支可選部隊：重步兵、弓兵、騎兵、英雄小隊。
- 固定軍令：推進、固守、攻擊、撤退、變換陣形。
- 每次軍令推進一個純函式戰鬥回合。
- PixiJS 讀取即時戰鬥狀態，不再讀取固定展示資料。
- 勝利後由玩家依序操作回收、返營、製造、裝備與再戰。
- 同 Seed 重設後，軍令序列產生相同結果。
- Playwright 以實際點擊完成閉環。

## 非目標

- 自然語言與 Workers AI，留在 Phase 7。
- 三路線、多節點遠征與臨時營地，留在 Phase 6。
- 灰牙狼群以外的四種魔獸，後續按 Phase 3 補齊。
- 存檔、多人與即時伺服器同步。

## 架構

### `packages/shared-types`

只新增跨套件穩定契約：固定軍令、戰鬥結果與必要事件類型。

### `packages/simulation-core`

新增純函式戰鬥回合解析器。輸入目前戰鬥狀態與軍令，輸出新狀態、事件與結果。移動、壓力、傷亡與 Seeded RNG 沿用既有模組。

### `apps/web/src/game-session`

以純 reducer 組合戰鬥與既有 progression-core。React 只保存狀態及送出玩家動作，不計算戰鬥結果。

### `packages/pixi-renderer`

不改規則。Web 將即時 `UnitState`／`MonsterGroupState` 轉成唯讀 `VisualUnitSource`。

## 玩家流程

1. 進入灰牙森林林間道路，選取部隊。
2. 按軍令後 Tick、兵力、位置、士氣與事件同步變化。
3. 灰牙狼群潰敗後出現戰利品操作。
4. 回收後返回基地，製造並裝備角甲重盾。
5. 點擊再戰，第二場狼群更強；重步兵外觀、防禦與移動已改變。
6. 玩家可隨時重設相同 Seed。

## 驗收

- 畫面至少有五種可操作軍令。
- 軍令會改變真實模擬狀態與戰場點群。
- 勝利與撤退皆可到達明確結果。
- 玩家能親自完成掉落到再戰閉環。
- 同 Seed 與相同軍令序列結果一致。
- E2E 必須包含 click，不能只驗證靜態文字。
- 相關測試先行；批次末只跑一次完整 `pnpm check` 與 E2E。
