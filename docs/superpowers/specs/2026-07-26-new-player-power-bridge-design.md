# 新人力量成長橋接設計

## 目標

讓第一次勝利不在回到公會後斷鏈，玩家會依序理解目標選擇、預演因果、Build 切換、第一次鍛造與下一場出擊。

## 已確認問題

- 首戰預選目標後，教學直接跳過「選目標」，玩家不知道敵人可點選。
- 預演只顯示事件數與擊殺數，沒有傷害、Overkill 與因果線索。
- 回公會後教學直接結束，Build、裝備、鍛造與下一場任務沒有串起來。
- 16 張卡同時出現在編輯器，低於舒適閱讀尺寸，也沒有建議換入路徑。

## 新人鏈

1. 明確點選教學指定目標，即使原本已預選也要收到操作確認。
2. 預演顯示「指令 → 觸發 → 總傷害 → 擊殺 → Overkill」。
3. 勝利回公會後切到推薦的彈射 Build。
4. 進入鍛造並完成一次結果可預見的強化。
5. 回到任務頁，以新 Build 開始下一場狩獵，才完成引導。

## 狀態與責任

- reducer 記錄玩家是否親自確認目標；不改戰鬥結果。
- coach 只根據既有狀態產生下一個 UI 焦點。
- 鍛造仍透過既有 `FORGE_ITEM` 行為執行，教學不建立特殊裝備。
- Build 推薦使用既有內容與預設牌組，不改數值。

## 漸進式卡牌編輯

- 初始先顯示目前 Build 的主動牌組與少量推薦候選。
- 提供「展開全部軍械庫」讓熟悉玩家查看全部 16 張。
- 顯示推薦理由與會連動的規則，不用玩家先閱讀所有卡。

## 邊界

- 不調整敵人、卡牌、鍛造成本、掉落或裝備強度。
- 不自動替玩家執行目標選擇、Build 啟用或鍛造。
- 跳過教學仍可立即結束整段流程。

## 驗收

- 首戰一定出現可操作的目標選擇步驟。
- 預演可看到總傷害、擊殺與 Overkill。
- 首勝後依序引導推薦 Build、鍛造與下一戰。
- 完成下一場出擊後教學狀態結束。
- 編輯器初始不再形成 16 張資訊牆，仍可手動展開全部。
- reducer、coach、元件測試與 `pnpm check` 通過。
