# SYSTEM BREAKER：AI 原生無美術 Roguelike 設計

日期：2026-07-24

狀態：待書面審閱

依使用者最新決策，本文件取代現代軍事沙盒與幻想軍團作為下一個玩家可見批次的產品方向；既有架構與測試規則繼續適用。

## 1. 一天版產品承諾

玩家輸入一句主題，AI 生成一套可驗證的「世界系統」。玩家在 8–12 分鐘內配置文字模組、觀察連鎖、承受反制，最後擊穿兩階段系統核心。

完成的體驗必須包含：

- 開場：世界目標、失敗條件與兩條特殊規則。
- 成長：2×2 裝備盤擴張成 3×3，並至少完成一次融合。
- 反制：七輪威脅逐步針對玩家的主要組合。
- 高潮：具有兩種不同反制的系統核心。
- 結局：通關或死亡、成績摘要、保存一件系統碎片、分享可重播局碼。

世界不預設幻想、軍事或任何固定題材；美術只使用文字、數字、CSS 色彩、邊框、進度條、格子高亮與連線。

## 2. 玩家循環

1. 輸入 1–240 字的世界概念，或使用範例提示。
2. 檢視 AI 生成的世界合約：目標、失敗條件、資源別名與世界規則。
3. 從三個文字模組中選一個，放入有限裝備格。
4. 購買、出售、融合或重新排列後按下「執行」。
5. 觀看最多十秒的確定性連鎖結算及原因日誌。
6. 擊破威脅後取得資金與新模組；失敗則失去完整度。
7. 第七輪擊穿系統核心，或因完整度歸零／不穩定度超限而死亡。

每輪準備階段最多提供三個新模組，玩家可跳過購買；戰鬥期間不需要輸入。

## 3. 固定狀態與主題別名

引擎只認識四種固定狀態：

- `PROGRESS`：達成當輪目標的產出。
- `INTEGRITY`：玩家生命，歸零時失敗。
- `INSTABILITY`：連鎖風險，達上限時失敗。
- `CREDITS`：購買、融合與刷新使用的貨幣。

AI 可依主題將它們顯示為配送量／公司完整度／熱度／資金等名稱，但不能改變語意。

## 4. 裝備盤與經濟

- 第 1–2 輪使用 2×2；完成第 2 輪後免費擴張為 3×3。
- 模組只佔一格，效果可指向自己、相鄰、上下左右、整列或全盤。
- 同名同級模組可支付固定費用融合；一天版最高二級。
- 融合提高既有效果數值或縮短冷卻，不生成新效果。
- 商店每輪三選一；售出返還固定比例，刷新次數有限。
- 所有價格、融合公式與售價由核心決定，AI 只可在允許區間提出基礎數值。

## 5. 模組規則語法

一個模組由名稱、稀有度、成本、冷卻、觸發、目標與效果組成。

允許的觸發：

- 回合開始、固定時間、相鄰模組發動、受到傷害、模組被停用、資源跨越門檻。

允許的效果：

- 產生進度、造成威脅傷害、修復完整度、增加／降低不穩定度、加速、放大下一效果、轉換資源、保護、停用、復原一次。

每個模組每條連鎖預設只能發動一次；只有明示的「再發一次」效果可額外發動一次。單次結算最多處理 32 個事件，超出時停止並記錄 `CHAIN_LIMIT_REACHED`。

## 6. 七輪成長弧線

1. 教學威脅：只檢查基礎產出。
2. 鄰接威脅：鼓勵形成第一個連鎖；勝利後擴張盤面。
3. 融合威脅：提供保證同名模組並教學融合。
4. 方向威脅：停用一個邊緣格，要求重新排列。
5. 過載威脅：高產出同時提高不穩定度。
6. 精英威脅：依玩家最高產出來源選擇預生成反制。
7. 系統核心：第一階段封鎖最高產出格；第二階段反轉左右效果或懲罰重複觸發。

威脅在準備階段完整公開，玩家可先調整盤面。AI 預先生成三個合法反制，核心依統計選擇，不在戰鬥中再次呼叫模型。

## 7. GameGenome

`GameGenome` 是 AI 與遊戲核心唯一共享的生成契約，包含：

- 版本、種子、標題、前提與四項顯示別名。
- 勝敗說明與兩條 `WorldRuleId`。
- 十二個合法模組定義，固定包含產出、放大、穩定、防禦與轉換角色。
- 七輪威脅，其中最後一輪是兩階段核心。
- 三個預生成反制與結局文字。

AI 不能輸出 JavaScript、公式、任意條件或未註冊效果；所有識別碼必須來自契約列舉。

## 8. 生成、驗證與備援

`POST /game-genomes` 接收提示與可選種子，透過 Cloudflare Workers AI 取得結構化草稿。

處理順序：

1. 限制提示長度並建立種子。
2. 呼叫模型一次，最多等待八秒。
3. 正規化名稱、列舉與允許區間。
4. 驗證模組、七輪結構、反制與必需欄位。
5. 執行固定策略的可玩性探測；結構或探測失敗時，以提示雜湊與種子建立本地備援 Genome。
6. 回傳 canonical Genome、`source: AI | FALLBACK` 與可重播種子。

戰鬥完全在瀏覽器的純核心執行；生成後不再呼叫 AI。相同 canonical Genome、玩家操作與種子必須得到相同結果。

## 9. UI 與無美術限制

預設入口只顯示 SYSTEM BREAKER：

- 世界合約與輪次。
- 下一個公開威脅。
- 2×2／3×3 文字裝備盤。
- 三選一商店、融合與出售控制。
- 四項狀態條、十秒結算與逐事件日誌。
- 通關／死亡摘要、最佳連鎖、以 localStorage 保存碎片，以及封裝 canonical Genome 與種子的可重播局碼。

格子發動時以 CSS 高亮；相鄰觸發以線條與方向箭頭呈現。不得加入 PNG、JPG、角色圖、裝備圖、Sprite Sheet、3D 模型、AI 圖片或音效資產。

既有遠征畫面暫存於開發用 `?legacy=1` 入口，避免一天批次混入大規模刪除。

## 10. 模組邊界

- `shared-types/system-breaker`：wire contracts 與列舉。
- `simulation-core/system-breaker/genome`：正規化、驗證與備援生成。
- `simulation-core/system-breaker/board`：盤面、購買、出售、融合與擺放。
- `simulation-core/system-breaker/chain`：固定 tick 與 32 事件上限。
- `simulation-core/system-breaker/run`：七輪、威脅、結局、評分與保存碎片。
- `worker-api/system-breaker`：Workers AI adapter、HTTP 驗證與 CORS。
- `web/system-breaker`：React reducer、畫面、動畫投影與 API client。

AI、HTTP 與 React 不得自行決定價格、觸發、傷害、勝敗或獎勵。

## 11. 驗收與測試

- 任意有效 Genome 都能建立一局；無效或未通過可玩性探測的 AI 草稿必定正規化或回退。
- Property tests 證明連鎖不超過 32 事件、狀態有限且相同種子結果一致。
- 核心測試涵蓋買賣、換位、融合、方向反轉、格子封鎖、過載、死亡與通關。
- UI 測試完成提示→合約→七輪→結局，並驗證碎片保存與局碼匯入。
- E2E 驗證預設入口可完成一局，`?legacy=1` 仍可開啟舊畫面。
- 批次完成後執行 `pnpm check`、production build 與線上 smoke test。

一天版不包含帳號、資料庫、多人、外部 Agent、製作器、市集、雲端收藏、AI 圖像／語音、任意程式生成或無限戰役。
