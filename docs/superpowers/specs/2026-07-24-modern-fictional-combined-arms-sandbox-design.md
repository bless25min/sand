# 現代啟發的虛構聯合作戰沙盒：產品重設設計

日期：2026-07-24

狀態：待審閱

定位：取代「幻想軍團 RPG」作為第一產品方向；保留自然語言軍令、養成與可重播戰術的核心價值。

## 1. 產品承諾

玩家在上帝視角指揮虛構國家的一支聯合特遣隊，投入有限兵力與資源，透過自然語言下達多條件軍令，在資訊不完整、通訊延遲與補給壓力下完成任務。

每個關卡的主要樂趣是：

- 以最少軍令回合獲勝，理想狀態是一道精心設計的複合軍令。
- 允許用多次追加軍令修正失誤，或養成後用簡單命令輾壓舊關卡。
- 從戰後回放理解勝敗原因，再調整編成、模組、資源與作戰條令。
- 保存成功戰術並快速重刷，但隊伍或裝備改變後必須重新驗證。

本作是規則透明、可重播的虛構情境模擬器，不宣稱預測真實戰爭。

## 2. 世界與安全邊界

- 使用虛構國家、虛構組織與通用能力分類，不直接複製現役部隊與精確武器性能。
- 優先使用程序化或虛構地圖；真實地形只能一般化，不接入當前衝突的兵力位置或目標座標。
- 不提供現實作戰部署、目標選擇、攻擊建議或精確殺傷校準。
- 模擬結果以遊戲模型、多組隨機種子與敏感度區間呈現，不當作現實決策依據。

## 3. 核心循環

1. 取得任務情報與不完整敵情。
2. 選擇任務編成、資源投入、載具／感測／通訊／防護模組與作戰條令。
3. 戰前輸入自然語言軍令，檢視系統轉譯後的結構化命令。
4. 開始模擬；軍令送出後不中斷時間，玩家以觀看為主，必要時可追加或下達緊急命令。
5. 戰後檢視事件時間線、傷亡、資源、情報誤差、命令延遲與關鍵轉折。
6. 獲得預算、技術、情報與熟練度，重整編成後再次挑戰。

關卡同時記錄「最少軍令」、「最快完成」、「最低損失」與「資源效率」，避免只有單一最優解。

## 4. 部隊與資源

教學由兩支特遣隊開始，關卡逐步解鎖四支與六支；底層引擎支援 N 支隊伍與群組命令。玩家可重複配置相同兵種，不設人工硬懲罰，改由地形、視野、通訊與補給自然形成代價。

六種基礎能力角色：

- 步兵／防禦：佔領、固守、近距接戰與掩護。
- 裝甲／高機動：突破、包抄、快速轉場，但消耗燃料與維修。
- 間接／遠程支援：對區域施壓，需要情報、彈藥與協同。
- 偵察／無人系統：偵察、中繼、誘餌與反無人系統。
- 電子／通訊支援：維持命令網路、干擾與反干擾。
- 後勤／醫療／維修：補給、救治、修復與維持作戰節奏。

主要資源包含人力、燃料、彈藥、維修、醫療、無人系統／電池、通訊頻寬、偵察資源、補給載具與任務時間。

## 5. 軍令系統

一次提交形成一個 `CommandTurn`，內含多個 `CommandClause`。軍階決定每次可用條件句上限；每個條件句可同時指定多支或全部隊伍。

條件句的清楚輸入輸出為：

- 輸入：對象、可觀測觸發條件、動作、目標區域、姿態／隊形、優先級、期限與失敗備案。
- 輸出：已解析、待傳遞、已套用、已過期、衝突或拒絕的可追蹤狀態。

限制與規則：

- 不允許無限迴圈、遞迴或「自行做最佳決策」等無界命令。
- 觸發條件預設只執行一次；持續條件具有冷卻與遲滯。
- 衝突順序固定為：緊急命令 > 玩家優先級 > 較晚送達命令 > 條件句順序。
- 同優先級且互相矛盾時，部隊猶豫並產生事件，不由 AI 靜默猜測。
- 戰前可反覆確認轉譯；戰中解析與傳令期間戰鬥持續進行。
- 結構格式錯誤由系統自動修復；語意誤解保留為玩法成本，並在「傳令回報」中清楚呈現。
- 撤退、停止追擊、原地固守是快速緊急信號，仍計入軍令並帶有秩序或士氣代價。

重播儲存原文、解析後命令、提交／解析／套用 tick、隨機種子與狀態雜湊；重播時不再次呼叫語言模型。

## 6. 戰場模擬與視覺

戰鬥由移動、接觸／直接火力、遠程／投射火力、範圍效應、感測與視野、通訊網路、補給消耗七種可組合規則構成。

部隊採「格網化可磨損編隊體」：

- 權威狀態是編隊格網與單元生命，不是兩千個各自思考的 AI 物件。
- 編隊整體移動；命中位置轉成局部格網傷害。
- 接觸攻擊磨損接觸邊緣，直射沿路徑穿透單元，範圍攻擊成片挖除。
- 傷害形成缺角、裂口、斷裂與潰退；生命較低時填色、裂紋與粒子密度同步改變。
- 碰撞足跡不隨受傷劇烈縮小，避免受傷反而更容易閃避。
- MVP 最多維持主體與一個脫離分隊，凝聚力恢復後可重組。

模擬使用固定 tick 與確定性規則，畫面以粒子投影與插值播放；只更新髒格網，避免逐單元兩兩碰撞與每幀配置物件。

## 7. 情報、通訊與無人系統

玩家只能看到己方 `FactionObservation`：已確認目標、最後已知位置、情報信心、可見區域與推測威脅。完整 `BattleTruth` 只供引擎與戰後分析。

命令延遲由距離、中繼、地形、干擾、指揮節點與指揮能力共同決定。通訊中斷會讓隊伍依最後命令、備案或預設姿態行動。

無人系統以偵察、中繼、電子支援、誘餌、區域支援與反無人能力呈現，不要求玩家手動駕駛。

## 8. 玩家自有 AI Agent

系統提供四層資料：`BattleTruth`、`FactionObservation`、精簡的 `AgentObservation`、`VisualProjection`。外部 Agent 只能讀取其陣營可見資料，不能直接修改位置、生命、資源或結果。

整合採 REST／WebSocket 核心與 MCP 門面，提供摘要、目標、友軍、可見敵情、區域、事件與命令佇列資源，以及提交命令、查詢衝突、檢查區域、等待決策事件、交還控制權等工具。

支援顧問、協同指揮與全自動三種模式；玩家可隨時停止 Agent 或接管。Agent 仍受軍階條件句上限、通訊延遲、戰場迷霧、命令成本、版本與速率限制約束。

Agent 以重大事件喚醒，不在每個 tick 呼叫。每次觀測版本、工具呼叫、命令、拒絕原因、隨機種子與狀態雜湊都寫入可稽核重播。

## 9. 養成、模組與戰術保存

裝備改為載具、感測器、通訊、防護、任務模組與作戰條令。模組必須改變行為、資源曲線、隊形或協同關係；只增加同類數值的內容不得成為獨立裝備。

保存戰術包含解析後命令、編成、模組指紋、部署、情境版本與種子規則。任何編成或模組變更都將結果標為「未驗證」，不自動調整舊戰術。

玩家可保存安全版、單軍令版、最快重刷版與新配置測試版；自動重刷與 Agent 同樣消耗補給、維修、恢復時間與任務成本。

## 10. 第一個可玩里程碑

- 一張虛構混合地形地圖、三個逐步解鎖二／四／六隊的任務。
- 六種能力角色、可重複編成、基礎感測／通訊／補給與格網磨損。
- 戰前自然語言軍令、戰中追加軍令、緊急信號、傳令回報與可重播時間線。
- 一組能以單一複合軍令、多次修正或養成輾壓三種方式完成的核心關卡。
- 戰後分析、四種成績指標、模組獎勵、保存戰術與未驗證標記。
- Agent 顧問模式與唯讀 `AgentObservation`；完整外部自動指揮列為下一里程碑。

驗收必須證明：相同種子與解析命令得到相同結果；不同攻擊形狀造成可辨識的磨損；專案參考桌機播放二千視覺單元時第 95 百分位影格時間不超過 16.7ms；Agent 看不到隱藏真相且不能改寫狀態；所有可玩路徑都有清楚回饋與失敗原因。

## 11. 技術邊界

- `simulation-core`：純規則、固定 tick、序列化狀態與事件，不依賴 UI、網路或 AI。
- `orders`：語意轉譯、結構驗證、衝突與傳遞；輸出只是一等公民命令。
- `battle-session`：組合核心、推進時間、保存快照／事件與授權命令。
- `observations`：由真實狀態產生玩家與 Agent 的霧化視圖。
- `renderer`：只讀視覺投影，不修改模擬狀態。
- `progression`：任務成本、獎勵、模組、編成與保存戰術。
- `agent-gateway`：權限、版本、冪等、速率限制與 MCP／WebSocket 介面。

雲端戰鬥可由每場一個 Durable Object／Agent 實例承載，以事件時點或有限時間片推進，而非永久執行 60 FPS 伺服器迴圈；瀏覽器依事件時間線流暢播放。
