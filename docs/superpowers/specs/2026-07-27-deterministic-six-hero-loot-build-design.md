# 確定性六人刷寶 Build 正式版設計

日期：2026-07-27
狀態：已確認，待書面審閱
取代範圍：先前 Guild RPG 的 Build 分類、八卡軍令、三人隊伍、角色等級成長、獨立技能寶石及只覆蓋戰鬥的引導規格。

## 產品目標

遊戲是刷寶養成 RPG，不是抽牌遊戲。樂趣來自定向刷取技能與裝備、組合規則、準備六人順序，並在戰鬥中確定地選擇技能，製造逐棒增強的接力爆發。不要用平衡或倍率壓低爽感；所有結果必須可讀、可預演、可重現。

完整循環：

`選任務 → 配六人／順序／36 技能／18 裝備 → 即時六棒戰鬥 → 取得技能／裝備／素材 → 融合／鍛造／重配 → 定向重刷`

## 固定介面與新手旅程

- 固定主導覽為 `任務｜隊伍｜技能｜裝備`；融合位於技能頁，鍛造位於裝備頁。
- 任務顯示敵人、規則、屬性、特化、觸發池、專屬核心與保證掉落。
- 隊伍顯示六人預設順序、角色特色、裝備與接力缺口。
- 技能頁逐人顯示六個欄位；卡片以屬性、特化、觸發、星級、固定值篩選與比較。
- 裝備頁顯示武器、防具、飾品、背包、核心規則、數值範圍、重鑄與移植。
- 引導以真實控制完成：認識四頁 → 排六人 → 配技能 → 穿裝備 → 看掉落 → 選目標 → 立即出招 → 臨時改序 → 六棒 → 領獎 → 二星融合 → 裝回 → 重刷。
- 每步只有一個焦點、短句、略過與重播；不得隱藏其他入口或遮住戰場。

## 六名角色

- 布蘭「不動鐵壁」：防護與格擋追加固定事件。
- 萊拉「破風鷹眼」：標記主目標並改造彈射返回路線。
- 艾琳「晨光祈禱者」：治療溢出成為後續可消耗事件。
- 賽芙「瘴芽鍊金師」：消耗層數時保留部分層數。
- 洛恩「裂界術師」：第一個範圍事件追加衝擊，單體時可折返。
- 凱洛「逐影連刃」：額外攻擊留下下一棒可用的殘響。
- 角色特色只追加固定事件；所有角色皆可裝備所有屬性、特化與觸發技能。

## 技能語法與內容量

每張技能由 `角色施放形式＋屬性＋特化＋觸發條件＋隨機固定整數` 組成；基礎效果永遠能執行，條件只控制追加效果。

屬性共三種：

- 火／燃燒：持續傷害、消耗、爆炸、連續引爆。
- 草／毒素：疊層、命中觸發、削弱、擴散。
- 水／潮汐：治療、護盾、溢出轉換、蒸氣迴響。
- 火遇毒素產生毒火；草遇潮汐產生腐化；水遇燃燒產生蒸氣。剋制以新增、消耗或轉換事件表現，不用倍率。

特化共六種：爆炸範圍、疊層、削弱、連鎖彈射、強化、攻擊次數。

觸發共三十種：

1. 使用技能、每次命中、追加命中、施加層數、消耗層數。
2. 目標有燃燒、毒素、潮汐、削弱、標記，或自身／隊友有護盾。
3. 燃燒、毒素、潮汐達門檻；第 N 次命中；治療溢出；成功格擋；護盾破裂。
4. 上一棒同屬性、形成元素反應、同特化、不同特化；目前為第二至第五棒；目前為第六棒。
5. 單一敵人、多名敵人、彈射完成、同目標迴響、擊殺、Overkill。

支援的基礎結構為 `3 × 6 × 30 = 540`。同屬性二星有 48,330 種配對，三星有 2,867,580 種三件組；共 2,916,450 種效果結構，尚未計入角色、欄位、裝備、順序及隨機值。

## 配置、融合與順序

- 每名角色戰前配置六個技能，戰鬥時六個全部可見、可用；不抽牌、不洗牌、不用隨機冷卻。
- 沒有主動／終結分類；任何技能都可因層數、接力位置或其他條件成為爆發。
- 二星融合兩張同屬性不同技能；三星加入第三張；融合技能只佔一格並依設定順序執行。
- 玩家可替換單一零件、調整順序、可逆拆解並完整取回原卡；只消耗融合素材。
- 戰前保存六人預設順序。每回合由預設開始，玩家可點任一尚未行動角色指定下一棒。
- 已行動角色鎖定；臨時改序只影響本回合；可恢復本回合預設或明確沿用至後續回合。
- 觸發條件依實際行動順序與位置重算，技能按鈕即時標示本次會成立的條件。

## 戰鬥與演出

- 點技能後立即結算與播放，再自動切換下一棒；不先配置六人再同時釋放。
- 每段依序執行基礎效果、狀態變更、條件檢查、追加事件與新事件入列。
- 傷害只使用固定值加減與多筆事件；移除玩家傷害、脆弱與 Overkill 的乘法倍率。
- 目標死亡自動重定向；全滅後剩餘事件轉為 Overkill；單體彈射可由條件折返回原目標。
- 同一來源只能觸發同一規則一次；封閉循環轉成「無限引擎」爆發，不能卡住。
- 演出隨真實事件數、層數、彈射、迴響及 Overkill 逐棒升級；第六棒沒有假大招。

## 刷取、裝備與鍛造

- 勝利掉落技能卡、武器／防具／飾品、屬性融合素材、敵人專屬鍛造素材；取消獨立技能寶石。
- 武器改造攻擊、次數、爆炸；防具改造護盾、治療、層數、削弱；飾品改造觸發、元素反應、彈射、迴響。
- 裝備與技能共用屬性／特化／觸發詞彙。普通裝備一個核心；稀有追加相關效果；傳奇有兩個可連動核心。
- 所有隨機值顯示實際值與可能範圍；不用隨機暴擊、機率觸發或隱藏戰力分。
- 鍛造只有範圍內調校、重鑄核心、鎖定、移植與分解；取消無限線性升級。
- 十二任務分成火、草、水各四關；每關公開特化／觸發池與專屬核心，普通勝利掉落 4–6 件，首領有保證掉落。
- 無自動出售；支援鎖定、收藏、批次分解及「新觸發／可融合／可補鏈／高數值」標記。

## 存檔、錯誤與畫面邊界

- Profile 升級 v4；v1–v3 可遷移。三人補成六人，八卡匯入收藏，舊規則裝備轉核心，等級／經驗轉融合與鍛造素材。
- 遷移前保留舊存檔備份；失敗不覆寫。刷新戰鬥回到最近安全狀態，不重發獎勵。
- simulation-core 擁有所有結果；game-data 擁有內容；shared-types 只放穩定契約；React 只送意圖與播放事件。
- 所有隨機使用注入 RandomSource，禁止 `Math.random`。
- 375×667、390×844、桌面必須同時容納任務／回合、六人順序、完整戰場、目標狀態、當前角色與 2×3 技能列。
- 詳細事件使用收合抽屜；教學、獎勵與播放控制不得遮蓋戰場；主要觸控至少 48px，水平溢位為零。
