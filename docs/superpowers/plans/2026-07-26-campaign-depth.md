# 戰役縱深實作計畫

## 批次成果

交付 4 區、12 場、18 種敵人、6 Boss、4 Build 的完整線性戰役，並在桌機與手機清楚呈現推進、區域轉場、完破及重玩。

## 任務一：穩定戰役契約

- 先在 game-data 測試要求區域、內容總數與完整引用。
- 新增 `ZoneDefinition`、`QuestDefinition.zoneId`、`GuildGameContent.zones`。
- 新增區域資料與戰役驗證器。
- 跑 game-data 內容測試與型別檢查。

## 任務二：四區作者內容

- 用內容工廠拆成四個可獨立閱讀的區域檔。
- 保留既有三場與八個敵人的身份、掉落及高潮。
- 補齊九場狩獵、十個新敵人與三名新 Boss，使總數精確達標。
- 每場加入唯一壓力、對策、敵人掉落、寶箱與三段高潮。
- 新增第四套「軍令風暴」Build。
- 跑內容、狩獵、戰鬥及掉落的受影響測試。

## 任務三：區域推進介面

- 先測試純函式戰役進度模型：locked / active / cleared、區域轉場與全戰役完破。
- 桌機將平面任務列改為四個區域戰線。
- 手機任務焦點顯示區域、全戰役進度、處刑順序、對策、掉落與完破重刷狀態。
- 保持所有主要操作至少 48px，375px 不橫向溢出。
- 跑受影響 UI 測試與 web build。

## 任務四：批次收尾

- 做一次整批程式碼審查並在同批修正重要問題。
- 跑 `pnpm check`。
- 建置、推送、部署 Cloudflare Pages。
- 驗證 immutable / canonical 資產雜湊與 375px、390px、桌機實際全流程。
- 記錄部署 ID、正式網址、測試數與實機證據。
