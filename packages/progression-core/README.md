# Progression Core

## Responsibility

Loot, inventory, crafting, and equipment effects.

## Public Input

- Battle results.
- Recipes.
- Inventory.
- `RandomSource`.

## Public Output

- Progression state updates.
- Progression events.

## Allowed Dependencies

- `@expedition/shared-types`.

## Forbidden Responsibilities

- React.
- PixiJS.
- HTTP.
- Battle simulation.
